# Security

cc-skins makes no network requests, reads no credentials and writes nothing to your projects; [Privacy and safety](docs/privacy.md) lists what it reads and runs.

If you find a security problem, please don't open a public issue: report it privately through GitHub's [security advisories](https://github.com/mr-dzzs21/cc-skins/security/advisories/new). You'll get an answer within a few days.
